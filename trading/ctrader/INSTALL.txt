-------------------------------------------------------------
 INSTALLATION SANS COPIER-COLLER  (recommandee)
-------------------------------------------------------------

1. Dezippe l'archive.

2. Copie les CINQ dossiers dans :

   Windows :  C:\Users\<toi>\Documents\cAlgo\Sources\Robots\
   macOS   :  ~/Documents/cAlgo/Sources/Robots/

   Tu dois obtenir par exemple :
   ~/Documents/cAlgo/Sources/Robots/GoldOrderFlow/GoldOrderFlow.cs
   ~/Documents/cAlgo/Sources/Robots/GoldOrderFlow/GoldOrderFlow.csproj

3. Redemarre cTrader.

4. Onglet Automate : les cinq robots apparaissent dans la liste.
   Clic droit sur chacun -> Build (ou ouvrir + F6).

-------------------------------------------------------------
 POURQUOI CINQ FICHIERS ET PAS UN SEUL
-------------------------------------------------------------

Un fichier unique voudrait dire un seul Build. Or une seule erreur
d'API dans une strategie ferait echouer la compilation des CINQ.

On a deja eu deux echecs de build sur des suppositions d'API
(PendingOrders.FindAll, puis ModifyPosition). Le moteur order flow
utilise MarketDepth, qui est la partie la plus incertaine de toutes.

Separes : si GoldOrderFlow ne compile pas chez ton courtier, les
quatre autres fonctionnent quand meme.

Tu veux quand meme un fichier unique ? C'est faisable, demande-le.
